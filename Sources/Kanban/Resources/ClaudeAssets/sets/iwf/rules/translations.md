## Sprach-Konventionen

| Element | Sprache |
|---------|---------|
| Branch-Namen | Englisch |
| Commit-Messages | Englisch |
| Code-Kommentare | Englisch |
| Variablen/Funktionen | Englisch |
| Translations | Nur DE bearbeiten (FR/IT werden übersetzt) |

## Übersetzungsdateien

- **Französische und italienische** Übersetzungsdateien im Ordner `translations/` werden **nie manuell bearbeitet**
- Diese Dateien werden von einem externen Übersetzungstool gepflegt
- Nur die **deutschen** Übersetzungsdateien (`*de*`) dürfen direkt geändert werden
